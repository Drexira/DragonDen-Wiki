Dragon Den - Weights and Raid Timer

What it does

  • • Change raid time per map
  • • Change item weight with global, per parent, or per item rules
  • • Optional whitelist and blacklist to target specific items

Features

Raid Time

  • • Set minutes per map.

Weight Changer

  • • Global percent applies to all items when no other match
  • • Per parent percent by item parent id or parent name
  • • Per item percent by exact item id or name
  • • Whitelist limits edits to listed items
  • • Blacklist excludes specific items and overrides all

Rule priority

  • • Per item over per parent
  • • Per parent over global
  • • Blacklist over everything

How to Use

Edit the config in DragonDen-WeightsAndRaidTimer/config. The config contains comments.

  • • Toggle features on or off
  • • Set minutes per map for raid length
  • • Set weight percents
  • • Add parent ids or names for category edits
  • • Add specific item ids or names for overrides
  • • Use the whitelist to restrict edits only to listed items
  • • Use the blacklist to protect items from any change

Compatibility

  • • Can be used with SVM but should be loaded after it and not using the same settings
  • • Load after all mods that add items or change raid settings
