Dragon Den - Dev Tool

What it is

  • • A simple in-raid window for development testing and messing around.
  • • It helps you heal, toggle protections, drop items, manage bots, teleport to extracts, and save teleport hotspots.
  • • Tabs: Player, Items, Bots, Exfils, Hotspots.
  • • Hotspot Maker tab shows up when Debug Mode is on.

How to open

  • Go into a raid.
  • Press Insert to show or hide the window. (or ESC to hide)

Player

  • Raid: Map. Time. Player counts. PMC. Scavs.
  • Player Info: Name. Side. Level. Position. Rotation. Copy Position. (rotation is based on inertia, not fully accurate)
    • • God Mode makes you the god of the tarkovians, nothing can hurt you.. probably... (always toggled on, can manually toggle off)
    • • No Fall Damage makes you immune to fall damage.
    • • Instant Search makes anything you search instant, like a true loot goblin..
    • • Infinite Stamina gives you infinite stamina for running, oxygen and hand stamina.
    • • Full Heal gives you full health and full energy and hydration. (includes loss of body parts)
    • • Clear Negative Effects will clear any bad effects like Pain, concussion, etc..
    • • Refill Hydration and Refill Energy, just what it sounds like.
  • Vitals: Health, Energy, Hydration, Body Temp, and current DamageCoeff.

Items

  • • Search by item name or item tpl id. Results are paged.
  • • Drop 1 spawns the item in front of you.
  • • Drop Amount lets you type a number. It uses the item max stack if it can stack and splits stacks as needed.

Bots

  • • Filter by id, nickname, or side.
  • • Each row shows Id, Nick, Side. Actions:
    • • To Me teleports that bot to you.
    • • Me to Them teleports you to them.
    • • Kill kills that bot.
  • • Teleport All pulls every bot to your position.
  • • Kill All kills all the bots on the map.
  • • Kill PMCs kills all PMCs on the map.
  • • Kill Scavs kills all the Scavs on the map.
  • • Kill Bosses kills all the Bosses on the map.
  • • Spawn Usec spawns 1 Usec somewhere.
  • • Spawn Bear spawns 1 Bear somewhere.
  • • Spawn Scav spawns 1 Assault Scav somewhere.
  • Spawn:
    • • a role from the popup.
    • • Type an amount from 1 to 50. (more than 20 can cause spawn errors)
    • • Press Spawn. It may take a few seconds for it to spawn, this is dependent on how many you try to spawn and how bsg's logic finds the closest zone to you.
    • Do note that if teleportation does not work, it's due to bad navigation, try to teleport them where you know they can actually walk to.

Exfils

  • • Choose which groups you want to see: PMC, Scav, Secret or all.
  • • Filter by name.
  • • Each result shows Name, Status, Type, Reusable, Chance, Queued, Position, timers, entry points, and tips for exfils like (Car: Bring X RUB).
  • • Teleport moves you to that exfil with a small Y lift.
    • Some extracts can drop you under the ground or out of bounds on some maps. If that happens teleport again or use a hotspot with a higher Y lift.

Hotspots

  • Two tabs:
    • • Global Hotspots has about 225 premade hotspots made, but you can edit these locally at BepInEx\plugins\DragonDenDevTool\hotspots_global.json.
    • • Favourite Hotspots are yours for the current map, can be seen in BepInEx\plugins\DragonDenDevTool\hotspots_favourites.json.
      • • The favourites can be made in the raid by naming and adding to favourite or adding an existing global hotspot.
  • Buttons:
    • • Teleport teleports you to the spot with the Y Lift offset.
    • • Favourite adds a global hotspot to your favourites if it is not already there.
    • • Remove deletes a favourite.
    • • Reload Hotspots reads the JSON files again and updates the list.

Hotspot Maker

This was made for the global hotspots, it's easier to add new favourites for you than using this.

  • • Only shows when Debug Mode is on from BepInEx Settings Menu.
  • • Shows the output file path. Lets you name a new hotspot and pick a category.
  • • Fetch Position grabs your current X Y Z.
  • • Teleport Test tries the position with a small Y offset.
  • • Add To File updates the global hotspots JSON.
  • • Fetch & Add To File updates position and updates the global hotspots JSON.
  • • Open Folder opens the plugin folder so you can see the files.

Settings

  • • Toggle UI: default is Insert. You can bind it in the BepInEx config.
  • • Update Interval: how often Player and Bots tab refreshes. Default 0.25 seconds.
  • • Debug Mode: shows Hotspot Maker and extra logs.
